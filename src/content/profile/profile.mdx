做前端这些年，最稳定的兴趣不是追新，而是把界面做得清楚、耐用、经得起回看。一个页面最终要被真实的人使用，也要被未来的自己维护，所以结构、语义、性能和可访问性从来不是附加项。

这个站点是一次重新整理。把过去的文章、项目和经历收进一个更轻的静态站点，用内容文件驱动页面，减少不必要的运行时。技术上选择 Astro 做内容外壳，交互只在水滴需要的地方出现；视觉上保留纸张、墨色与朱砂的克制关系。

写作会围绕 Web 前端展开：CSS 布局与容器查询、Canvas 与动效、框架取舍、构建与性能，也会记录一些工程判断和长期维护的经验。比起罗列结论，更希望写清楚问题是怎么被定义、方案为什么成立，以及在哪些边界上会失效。

如果这些内容对你有帮助，欢迎通过 GitHub 联系。站点会继续更新，但不会为了更新而更新；能长期使用的答案，比短期热闹更重要。
