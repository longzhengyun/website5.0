## 背景

旧站停留在 Next.js 10 的半成品阶段，登录、API 与数据库没有被真正使用，却给维护带来持续成本。5.0 的目标是回到内容站本身：文章、项目、关于与一组基础 SEO 能力。

## 目标

- 静态输出，无登录、无数据库、无服务端 API
- 桌面与移动端都保持克制的阅读体验
- 用内容文件驱动页面，新增内容不改代码
- 首屏性能与可访问性达到可验收标准

## 方案

页面外壳使用 Astro，正文使用 MDX 内容集合；交互只保留主题切换、搜索与少量岛屿。首页地球在桌面使用 Canvas 2D 运行时，移动端加载静态海报。

构建后由 Pagefind 生成中文索引，Cloudflare Pages 负责预览与静态托管。

## 难点

最大的取舍不在框架，而在内容边界：分类筛选必须改成静态路由，搜索必须完全客户端化，旧链接需要重定向策略。这些问题在写页面前先定清楚，返工明显更少。

## 结果

当前处于 M2 骨架阶段：内容集合、路由、主题、搜索、RSS、sitemap 与 404 已跑通，页面视觉将在设计验收后继续接入。
